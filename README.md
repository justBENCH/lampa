# Online Mod Direct Play

Кнопка Play в карточке Lampa сразу открывает установленный Online Mod, пропуская меню «Источник». Рядом с Play расположена штатная кнопка «Трейлеры», открывающая список роликов Lampa. Она появляется только у карточек с доступными трейлерами. Выбор перевода, серии и качества внутри Online Mod работает как обычно.

## Установка

1. Оставьте Online Mod установленным.
2. Разместите `online-mod-direct-play.js` на доступном HTTPS-хостинге (например, GitHub Pages).
3. В Lampa откройте **Настройки → Расширения → Добавить плагин** и укажите прямую HTTPS-ссылку на файл.
4. Перезагрузите Lampa.

Настройка применяется в том браузере и на том адресе Lampa, где добавлен плагин. Для телевизора добавьте ссылку в его Lampa отдельно.

## Поведение

- Вызывает штатный обработчик Online Mod из меню источников, до отображения меню.
- Узнаёт Online Mod по классу `view--online_mod`, а не по переведённому названию.
- Остальные меню, включая меню внутри Online Mod, не меняются.
- Если Online Mod отсутствует или скрыт, открывается обычное меню источников.
- Если Lampa показывает отдельную приоритетную кнопку Online Mod и исключает её из меню Play, снимите приоритет долгим нажатием на эту отдельную кнопку.
- Чтобы вернуть прежнее поведение, удалите вспомогательный плагин из расширений и перезагрузите Lampa.

## Совместимость и проверка

Реализация сверена с исходниками `yumata/lampa-source` и `nb557/plugins/online_mod.js`, загруженными 14 сентября 2026 года. Использует `Lampa.Select.show`, `settings_rest_source` и поле `btn` элементов меню. Изменения этих интерфейсов в будущих версиях Lampa могут потребовать обновления.

Локальные проверки покрывают прямой запуск, отсутствие/скрытие Online Mod, другие меню, повторную загрузку и отложенную готовность Lampa. В локальной веб-сборке проверено на карточке «Хитрый койот»: без плагина Play открывает «Источник», с плагином сразу открывается Online Mod со списком переводов. Воспроизведение видео и работа на телевизоре не проверялись. Сам плагин не делает сетевых запросов и не читает учётные данные.

Исходники: https://github.com/yumata/lampa-source и https://github.com/nb557/plugins

Версия 1.1.0: штатная кнопка трейлеров перемещается из меню источников непосредственно после Play с сохранением её обработчика. Открытие списка трейлеров проверено в локальном браузере.

## Релиз 1.1.1

Добавлены проверки готовности API Lampa и неполных событий карточки. JavaScript написан в синтаксисе ES5 для старых ТВ-браузеров; совместимость конкретного телевизора требует проверки на устройстве.

Для GitHub Pages: загрузите файл плагина в публичный репозиторий, затем включите Settings → Pages → Deploy from a branch → main / (root). В расширения Lampa добавляется адрес самого `.js`, не страница репозитория. Online Mod устанавливается отдельно. После обновления плагина перезапустите Lampa.
